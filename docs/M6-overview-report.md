# M6 · 月总览

一句话：标题栏多了个日历按钮（点顶部「今日进度」那块也行），打开是一整屏的月视图 ——
哪天有活、哪天干完了、这个月一共多少条，一眼看完。

## 1. 做了什么

| 元素 | 说明 |
| --- | --- |
| 入口 | 标题栏日历按钮（主题按钮左边）+ 顶部「今日进度」那块（`button.hero-block.tap`） |
| 月网格 | 周一开头，固定 6 行 × 7 列 = 42 格（翻月不跳高度）；列头 `一 二 三 四 五 六 日` |
| 每格内容 | 日期数字 + 「已完成 / 当天条数」；全干完的那天显示 `✓` |
| 配色 | 还有没干完 → 蓝底（`--accent-soft`）；全干完 → 绿底（`--ok-soft`）；今天与「正在看的那天」有描边；补白格子透明 |
| 点击 | 点某一天 → **就地**选中它（面板不关）并在第三张卡里列出那天的任务（与 `list_by_day` 同一个命令，所以重复任务的展开行也在）；想真跳过去点卡片右上角「在列表里打开这天」（`onPick` → `setDay`） |
| 翻月 | `‹` `›`；看的不是本月时出现「回到本月」 |
| 本月合计 | 本月 N 条 / 已完成 / 未完成 / 完成率 % + 进度条 |
| 第二张卡 | 有任务的天数、已经全干完的天数、最忙的一天、还剩几天有没干完的 |
| 第三张卡（选中那天） | 时间 / 标题 / 重复标记（↻）/ 「已完成 · 未完成」；默认选中打开总览时正在看的那天，空的那天显示「这天没有任务。」 |
| 空月 | 显示全 0、「最忙的一天：还没安排」，不报错 |

统计口径：**跟周条、页脚共用后端 `countTasksByDay`**（按天展开重复任务算出来的那个）。
网格里上个月末尾 / 下个月开头的补白格只显示日期、不参与统计。

## 2. 三个决定

1. **统计走后端，不在前端自己数**：前端把任务表拉回来自己按天算，会跟「重复任务展开」的规则
   （`day` 是起始日、展开行 `repeated=true`、`occurrences.state`）不一致 —— 周条/页脚用的是
   `db::count_by_day`（内部逐天 `tasks_on_day`），月总览必须用同一个，否则同一台机器上三个地方三个数。
2. **固定 42 格而不是按月份长度出 4~6 行**：翻月时高度不跳（跳一下比多两行空白难受）。
3. **月份计算放 `src/day.ts`**（`monthStart` / `shiftMonth` / `monthEnd` / `monthLabel` / `monthGrid`）：
   项目约定是「日期计算只有这一个出处」，且继续**不用 `toISOString()`**（那段注释里写了原因）。
   `shiftMonth` 固定以 1 号为基准 —— 拿 31 号加一个月，JS 的 `Date` 会滚动进位到下下个月。

## 3. 实测证据（CDP 走真实界面）

| 步骤 | 实测 |
| --- | --- |
| 打开 | `button.hero-block.tap` 存在 1 个；点开后面板 head = `月总览` |
| 网格 | `.month .md` = **42** 格，其中本月 **31** 格、补白 **11** 格；列头 `一二三四五六日` |
| 本月合计 | `本月 6 条 · 已完成 3 · 未完成 3 · 完成率 50%`（10-08 两条全完成 + 10-09 四条里完成 1 条 = 6 / 3 / 3 ✓） |
| 格子徽标 | `8=✓`（那天全干完）、`9=1/4`（还有没干完的） |
| 第二张卡 | 有任务的天数 `2 / 31 天`、已经全干完的天 `1 天`、最忙的一天 `10-09（4 条）`、还剩几天 `1 天` |
| 翻月 | `‹` → `2026 年 9 月`（0 条、全 0、`最忙的一天：还没安排`、出现「回到本月」）；点它 → 回到 `2026 年 10 月` |
| 第三张卡（选中那天） | 打开时默认就是「正在看的那天」：`10-08 周四` + `2 条`；两条任务分别带时间 `17:27` / `17:30`、标题与「已完成」；点 `10` 号（没任务）→ `10-10 周六 0 条` + 「这天没有任务。」 |
| 点格子就地列任务 | 点 `8` 号格 → **面板不关**、`sel` 描边移到 `8`、第三张卡换成 `10-08 周四 · 2 条`（两条带时间与状态） |
| 点补白格 | 点下月补白格 `8` → 第三张卡显示 `11-08 周日 0 条`（跨月的天也能查，不切月） |
| 真的跳过去 | 点「在列表里打开这天」→ 面板关掉、周条选中 `周日 11-08`（这就是以前点格子的行为） |
| 控制台 | 只有 `[TAURI] Couldn't find callback id …`（reload 时的正常噪音），无报错 |

## 5. 已知缺口

1. 只看「条数」，不看**工时/时长**（任务没有时长字段）。
2. 不显示「未完成的都叫什么」——想看具体是哪些还得点进去那天。
3. 月网格里**不画远期重复任务**（如「每天」）之后的实发次数：显示的是 `count_by_day` 会展开的那些天，
   而展开窗口是 7 天（`MAX_EXPAND_DAYS`），所以很远的未来格子可能暂时没有数字。
4. 不能拖拽任务改日期、不能在总览里直接勾完成（只在列表里勾）。
5. 闰月 / 跨年的月份标签只到「YYYY 年 M 月」，没做农历、节假日标注。
6. 「还剩几天有没干完的」按**今天及以后**算，看别的月份时显示「看的是别的月」。
